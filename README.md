# By.Niadania — Editorial Beauty Website

Responsive static website concept for By.Niadania with editorial styling, Fraunces headline typography with improved line spacing and readability, motion, gallery filters, service price draft, and a booking request form that prepares a WhatsApp message.

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` with Live Server, or open the file directly in a browser.
4. Internet access is used for Google Fonts and temporary Unsplash images.

## Important before publishing
- `assets/logo-by-niadania.jpg` contains the supplied logo.
- Replace temporary gallery/hero images with photos of actual By.Niadania work that the owner approves.
- Price list is a DRAFT read from supplied screenshots. Verify every price and package.
- Confirm the WhatsApp number before launch.
- Add the owner's real Google Form URL in `script.js` at `GOOGLE_FORM_URL`.
- Confirm operating hours, address, DP amount, booking/cancellation policy, and actual services.
- The website does not reserve time slots or process DP payments. WhatsApp messages are not sent until the customer presses Send.
- Test the site on mobile and desktop before publishing.

## Files
- `index.html` — page content
- `style.css` — design, responsive layout, and animations
- `script.js` — interactions, gallery filtering, booking summary, WhatsApp handoff, optional Google Form link
- `assets/` — supplied logo
